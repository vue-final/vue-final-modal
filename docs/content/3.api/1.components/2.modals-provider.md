---
title: '<ModalsProvider>'
description: 'The provider component that powers Vue Final Modal.'
---

`<ModalsProvider>`{lang=ts} wraps your app once and does two things:

1. Provides the shared modal context (through provide/inject) that `<VueFinalModal>`{lang=ts} and the composables rely on.
2. Hosts the Vue instances of the dynamic modals created by [useModal()](/api/composables/use-modal).

You don't need to add anything else to the `<ModalsProvider>`{lang=ts}. As long as your app is wrapped with it, every feature of Vue Final Modal is available.

```vue [App.vue]
<script setup lang="ts">
import { ModalsProvider } from 'vue-final-modal'
</script>

<template>
  <ModalsProvider>
    <!-- Your app -->
  </ModalsProvider>
</template>
```

::note
`<VueFinalModal>`{lang=ts} throws an error when it is used outside of `<ModalsProvider>`{lang=ts}, so put the provider at the root of your app.
::

## Advanced: isolated instances

For advanced scenarios (e.g. micro frontends) you can create an isolated provider with its own `useModal()`{lang=ts} and `useVfm()`{lang=ts} that don't share state with the default one:

```ts
import { createModalsProvider } from 'vue-final-modal'

const { ModalsProvider, useModal, useVfm } = createModalsProvider()
```
