## Usage

```vue
<script setup lang="ts">
import { useVfm } from 'vue-final-modal'

const vfm = useVfm()
const {
  modals,
  openedModals,
  get,
  toggle,
  open,
  close,
  closeAll,
} = vfm
</script>
```

## Global state

- `vfm.modals`{lang=ts}: All modals including opened and closed modals.
- `vfm.openedModals`{lang=ts}: All opened modals.

## Functions

`vfm` instance provides some utility functions that allows you to operate a modal (see [modalId](/api/components/vue-final-modal#modalid-optional)) or modals.

- `vfm.get(modalId)`{lang=ts}: Get a modal instance by given a modalId
- `vfm.toggle(modalId, show?)`{lang=ts}: Toggle a modal by given a modalId, or open it with `show: true`{lang=ts} and close it with `show: false`{lang=ts}
  ```ts
  vfm.toggle(modalId).then(() => {
    // Do something after the modal opened or closed
  })
  ```
- `vfm.open(modalId)`{lang=ts}: Open a modal by given a modalId
  ```ts
  vfm.open(modalId).then(() => {
    // Do something after the modal opened
  })
  ```
- `vfm.close(modalId)`{lang=ts}: Close a modal by given a modalId
  ```ts
  vfm.close(modalId).then(() => {
    // Do something after the modal closed
  })
  ```
- `vfm.closeAll()`{lang=ts}: Close all opened modals. It resolves with the `Promise.allSettled()`{lang=ts} results of their closing.
  ```ts
  vfm.closeAll().then(() => {
    // Do something after all modals closed
  })
  ```

`get()`{lang=ts}, `toggle()`{lang=ts}, `open()`{lang=ts} and `close()`{lang=ts} return `undefined`{lang=ts} when no modal has that modalId. Their promises always settle: with `'opened'`{lang=ts} or `'closed'`{lang=ts}, or with a message when the modal did not get there, see [what open() and close() resolve with](/api/composables/use-modal#what-open-and-close-resolve-with).
