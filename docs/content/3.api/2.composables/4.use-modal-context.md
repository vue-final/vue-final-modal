---
title: 'useModalContext()'
description: 'Close and name the modal from any component rendered in it.'
---

The default slot of [\<VueFinalModal>](/api/components/vue-final-modal#slots) and [\<VueFinalDialog>](/api/components/vue-final-dialog#slots) passes a `close`{lang=ts}, a `titleId`{lang=ts} and a `descriptionId`{lang=ts}. A component given in the `slots`{lang=ts} of [useModal()](/api/composables/use-modal) does not receive them as slot props: it reads the same values with `useModalContext()`{lang=ts}, as does any component nested deeper in the modal.

## Usage

```vue [ModalContent.vue]
<script setup lang="ts">
import { useModalContext } from 'vue-final-modal'

const modal = useModalContext()
</script>

<template>
  <h2 :id="modal?.titleId">Delete the file?</h2>
  <p :id="modal?.descriptionId">It cannot be restored.</p>
  <button @click="modal?.close()">Cancel</button>
</template>
```

```ts
import { useModal, VueFinalModal } from 'vue-final-modal'
import ModalContent from './ModalContent.vue'

const { open } = useModal({
  component: VueFinalModal,
  slots: { default: ModalContent },
})
```

The modal gets `aria-labelledby`{lang=ts} and `aria-describedby`{lang=ts} pointing at the title and the description once they are rendered, see [Accessibility](/get-started/guide/accessibility#a-name). `close()`{lang=ts} closes the modal like the `close`{lang=ts} of the slot.

In a modal nested in another one, `useModalContext()`{lang=ts} returns the context of the closest modal. Outside a modal it returns `undefined`{lang=ts}.

## Type Declarations

```ts
interface ModalContext {
  close: () => void
  titleId: string
  descriptionId: string
}

function useModalContext(): ModalContext | undefined
```
