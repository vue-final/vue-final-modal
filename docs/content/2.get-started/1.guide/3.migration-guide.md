## Migrating from 4.x to 5.0

vue-final-modal 5.0 removes the Vue plugin in favor of a provider component, and rebuilds `useModal()`{lang=ts} on top of [vue-use-template](https://github.com/hunterliu1003/vue-use-template).

The `<VueFinalModal>`{lang=ts} component itself (props, events, slots) stays almost the same — most of the changes are about how modals are registered and controlled programmatically.

## Step by step

### Removed `createVfm()` — use `<ModalsProvider>` instead

There is no Vue plugin to install anymore. Wrap your app with `<ModalsProvider>`{lang=ts} instead.

#### In Vue 3

So this:

```ts [main.ts]
import { createVfm } from 'vue-final-modal'

const vfm = createVfm()
app.use(vfm)
```

Will be re-written as this:

```vue [App.vue]
<script setup lang="ts">
import { ModalsProvider } from 'vue-final-modal'
</script>

<template>
  <ModalsProvider>
    <!-- Your app -->
  </ModalsProvider>
</template>
```

#### In Nuxt

The `@vue-final-modal/nuxt` module no longer registers a plugin. Keep the module for the CSS, and wrap your app with `<ModalsProvider>`{lang=ts}:

```vue [app/app.vue]
<script setup lang="ts">
import { ModalsProvider } from 'vue-final-modal'
</script>

<template>
  <ModalsProvider>
    <NuxtPage />
  </ModalsProvider>
</template>
```

### Removed `<ModalsContainer>`

`<ModalsProvider>`{lang=ts} hosts the dynamic modals by itself, so `<ModalsContainer />`{lang=ts} is gone. Simply delete it from your templates.

### `useModal()` returns `show` / `hide`

So this:

```ts
const { open, close } = useModal({
  component: ModalConfirm,
  attrs: {
    title: 'Hello World!',
    onConfirm() {
      close()
    },
  },
})

open()
```

Will be re-written as this:

```ts
const { show, hide } = useModal({
  component: ModalConfirm,
  attrs: {
    title: 'Hello World!',
    onConfirm() {
      hide()
    },
  },
})

show()
```

Note that `component`{lang=ts} is required now — pass `VueFinalModal`{lang=ts} explicitly if you were relying on the old default.

### Moved `defaultModelValue` and `keepAlive` to options

`useModal()`{lang=ts} now takes a second argument for the behavior options:

```ts
const { show, hide } = useModal({
  component: ModalConfirm,
  attrs: { ... },
}, {
  // Replaces `defaultModelValue: true`
  showByDefault: false,
  // The modal is automatically hidden when the component that created it unmounts
  hideOnUnmounted: true,
})
```

`keepAlive`{lang=ts} and `destroy()`{lang=ts} are removed.

### Removed `patchOptions()` — use a reactive template

Instead of patching the modal imperatively, pass a `ref`{lang=ts}, `computed`{lang=ts} or getter function as the template. The modal stays in sync with it:

So this:

```ts
const modal = useModal({
  component: ModalConfirm,
  attrs: { title: 'Hello World!' },
})

modal.patchOptions({ attrs: { title: 'Hello Vue!' } })
```

Will be re-written as this:

```ts
const title = ref('Hello World!')

const { show, hide } = useModal(() => ({
  component: ModalConfirm,
  attrs: { title: title.value },
}))

title.value = 'Hello Vue!'
```

### Removed `useModalSlot()` — use `defineTemplate()`

```ts
import { defineTemplate, useModal } from 'vue-final-modal'

const { show } = useModal({
  component: VueFinalModal,
  slots: {
    default: defineTemplate({
      component: ModalContent,
      attrs: {
        title: 'Hello world!',
        onConfirm() { },
      },
    }),
  },
})
```

### Removed `$vfm` global property

`this.$vfm`{lang=ts} in Options API is gone. Use the `useVfm()`{lang=ts} composable:

```ts
import { useVfm } from 'vue-final-modal'

const vfm = useVfm()

vfm.open(modalId)
vfm.close(modalId)
vfm.closeAll()
```

### Summary

| 4.x                                  | 5.0                                                        |
| ------------------------------------ | ---------------------------------------------------------- |
| `createVfm()` + `app.use(vfm)`       | [\<ModalsProvider>](/api/components/modals-provider)       |
| `<ModalsContainer />`                | Removed — handled by `<ModalsProvider>`                    |
| `useModal().open()` / `.close()`     | [useModal().show() / .hide()](/api/composables/use-modal)  |
| `defaultModelValue`                  | `showByDefault` option                                     |
| `keepAlive` / `destroy()`            | Removed — see `hideOnUnmounted` option                     |
| `patchOptions()`                     | Reactive template (`ref` / `computed` / getter)            |
| `useModalSlot()`                     | `defineTemplate()`                                         |
| `this.$vfm`                          | [useVfm()](/api/composables/use-vfm)                       |

## Migrating from 3.x to 4.0

Please check the [vue-final-modal 4.x documentation](https://v4.vue-final-modal.org) for the 3.x to 4.0 migration guide, then migrate to 5.0 from there.
